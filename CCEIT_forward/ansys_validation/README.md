# Maxwell 2D AC Conduction check

This optional workflow builds and solves a voltage-driven 16-electrode
AC-conduction case in Ansys Maxwell, then reduces the exported terminal matrix
to 120 pair responses. It is separate from the Octave/EIDORS workflow and does
not modify EIDORS results.

## Run through the Maxwell GUI

Use Ansys Electronics Desktop v252 or a compatible Maxwell 2D installation.
The working path is the GUI; the PowerShell launcher is experimental because
the installed AEDT CLI project APIs failed to create/open a project reliably.

1. Open Ansys Electronics Desktop.
2. Create a **new blank project** without adding a design.
3. Select **Tools > Run Script** and run `run_b6_maxwell.py` from this folder.
4. Wait for the AC Conduction solve and raw matrix reports to finish. The
   script saves `results/B6_Maxwell_ACConduction.aedt` and four matrix CSVs.
5. In the same GUI, select **Tools > Run Script** and run
   `export_ymatrix_csv.py`. It writes `results/B6_Maxwell_pairs_120.csv`.

Start with a fresh blank project on a new model run. The script inserts a
design and creates geometry; rerunning it in the same project can collide with
that design. The exporter may also be run from PowerShell at the repository
root:

```powershell
py ansys_validation\export_ymatrix_csv.py
```

The exporter uses only Python's standard library, so it also works in AEDT's
script runner. It prefers direct `Re(Y)` and `Im(Y)` reports, reconstructs the
full 16-terminal matrix by current conservation, and floats the other 14
electrodes for each transmitter/receiver pair. Its four columns are
`Yreal,Yim,abs_Y,phase`; rows follow acquisition order `(1,2), (1,3), ...`.

## Model settings and interpretation

- Frequency: 500 kHz; 2D model depth: 1 m.
- Medium disk radius: 53 mm; outer radius: 55 mm; 16 electrode arcs with
  nominal 18 mm arc width.
- Medium material: `sigma=0.025 S/m`, `epsr=80`.
- Layer/contact construction: radial bands from 53 to 54 mm and 54 to 55 mm.
  The dielectric uses `sigma=1e-12 S/m`, `epsr=1.58`; electrode contact
  sectors use `sigma=0.1 S/m`, `epsr=10`. The 1 mm resistive contact sector
  approximates `z_el=0.01 Ohm.m`; the thin dielectric's permittivity is scaled
  to represent the nominal 2 mm, `epsr=3` layer in this coarse geometry.
- The script sets `InsulatorThreshold=1e-8 S/m`. This setting is essential:
  Maxwell would otherwise classify the `0.025 S/m` medium as an insulator and
  discard its conductive current, making `Re(Y)` zero and phase approximately
  90 degrees.
- To fit the AEDT Student mesh limit, electrode arcs are polygonal (4 segments
  per electrode and 1 per gap) and the solve uses one adaptive pass.

The Maxwell mesh is generated by Maxwell; it is not the Netgen EIDORS element
mesh. The boundary layout and terminal protocol are similar, but contact
impedance is approximated by a resistive material sector. This is a useful
independent forward-solver check, not an identical-mesh or mesh-converged
quantitative validation. Compare the exported 120-pair data while stating
these differences.

## Output files

Created under `results/`:

- `B6_Maxwell_ACConduction.aedt`: solved Maxwell project.
- `B6_Maxwell_G_uS.csv`, `B6_Maxwell_C_pF.csv`: conductance/capacitance matrix
  reports with electrode 16 as the reference.
- `B6_Maxwell_Yre_uS.csv`, `B6_Maxwell_Yim_uS.csv`: direct real and imaginary
  admittance matrix reports used by the current exporter when available.
- `B6_Maxwell_pairs_120.csv`: the 120 floating-pair outputs.

If the Maxwell script reports that `Re(Y)` or `G` is identically zero despite
nonzero medium conductivity, do not use the pair CSV; check the material
threshold setting and rerun the solve. If the GUI's Messages panel still shows
an earlier error, check the latest solve completion and CSV modification
times—the panel can retain messages from previous attempts.
